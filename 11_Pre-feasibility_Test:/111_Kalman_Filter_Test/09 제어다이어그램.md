## 2. 제어 다이어그램 구성 요소 상세 설명
문서 작성 시 각 블록의 역할을 설명하기 좋도록 세부 내용을 정리해 드립니다.
- 지연 보정 알고리즘 (Latency Compensation Block):
  - 카메라 이미지 연산에 걸린 시간(50ms) 동안 컨베이어가 이동한 거리($v_{\text{target}} \times \Delta t_{\text{delay}}$)를 계산합니다.
  - 과거의 센서 데이터를 현재 시점의 데이터로 강제 변환하여 칼만 필터의 시차 왜곡을 제거합니다.
- 칼만 필터 모듈 (KF Predict & Update):
  - Predict (10ms): 로봇의 제어 명령과 컨베이어의 물리 법칙을 바탕으로 로봇 및 타겟의 다음 위치를 고속 예측합니다.
  - Update (50ms): 지연 보정된 비전 데이터가 들어올 때만 동작하며, 노이즈($R$)를 걸러내고 타겟의 정확한 참값 위치와 속도를 추출합니다.
- 축별 독립 제어기 구조 (X, Y, Z Controller):
  - X축 (이송축): 컨베이어가 직접 움직이는 축이므로 [P 제어 + 속도 피드포워드] 구조를 가집니다. 이를 통해 로봇이 타겟 뒤로 쳐지는 현상(Lag)을 방지합니다.
  - Y축 (정지/정밀축): 오차가 물리적 0으로 수렴해야 조립이 가능한 축입니다. 목표점 근처에서 기어가며 느려지는 현상을 막기 위해 [PI 제어]를 적용하며, 급격한 오차 적분 상승을 막는 [Anti-windup 필터]가 결합되어 있습니다.
  - Z축 (하강축): 타겟과의 높이 방향 정렬을 위한 기본 [P 제어] 구조입니다.
